# Custom GPT Project — Topic 1

## Project

**CampusGuide GPT: College Student Help Assistant**

## Files

* `use\_case\_document.md` — the main Topic 1 deliverable.
* `README.md` — this project overview.

## How to use

1. Extract the ZIP file.
2. Open `use\_case\_document.md` in VS Code, Notepad, or another Markdown editor.
3. Review the project and replace any assumptions with details relevant to your college.
4. Before creating a GPT, gather only approved, current, non-sensitive reference documents.
5. Test the proposed assistant against common questions and the validation plan in the document.

## Important

This project document defines a proposed use case. It does not mean that a Custom GPT has already been built or tested. The success measures are pilot targets, not measured results.
